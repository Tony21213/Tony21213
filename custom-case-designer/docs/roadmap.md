# Дорожная карта

## Что должно получиться

Некоммерческая программа для Windows, в которой техник или врач собирает
цифровой кейс пациента в одной системе координат и без потерь передаёт его в
exocad.

1. **КТ.** Полночерепная КЛКТ, сегментация набором структур как у OdentAI:
   зубы, челюсти, каналы, пазухи, череп, дыхательные пути. Модели открытые,
   с указанием лицензий и авторов.
2. **Сканы на КТ.** Интраоральные сканы и сканы гипсовых моделей (с цоколем)
   точно совмещаются с КТ по коронкам. Пользователь может поправить посадку,
   программа учится на его поправках.
3. **Единые координаты.** Все 3D-объекты выгружаются в одной системе: сканера
   (exocad) или КТ (DICOM). Два режима прикуса, приоритет у прикуса со сканов.
4. **Ориентиры и плоскости.** Цефалометрический анализ по КТ, плоскости
   Франкфурта, HIP и Кампера. Выгрузка в координатах виртуальных артикуляторов
   exocad.
5. **Эстетика.** Фронтальное фото в естественном положении головы, профиль
   по желанию. Эстетический горизонт и средняя линия не совпадают с костными
   ориентирами, а зрачковая линия ненадёжна. Сканы и модели выгружаются и в
   эстетической системе.
6. **Артикулятор и движения.**
   - Монтаж по эстетической плоскости с асимметричными мыщелками.
   - Углы суставного пути берутся из реальных данных: бугорок по КТ,
     стёртость по сканам, записи движений (P-ART и другие системы).
   - Траектории, построенные по движению (FGP), и контакты по зубам.
   - Для скольжения по зубам используются только сканы, модели зубов из КТ
     не подходят.
7. **exocad.** Кейс открывается в exocad без ручной расстановки: правильные
   имена файлов и проект. Кнопки в exocad ведут к нашим функциям, например к
   генерации сот и к библиотекам. Подключение только официальными средствами
   и форматами: без вмешательства в код exocad.
8. **Интерфейс.** Спокойный, рабочий, без лишних кнопок и без вида «сделано ИИ».

## Этапы

### 0.1: первый рабочий билд
Сегментация, совмещение, экспорт.
- Выложить модели в релиз `models-v1` (локальная сессия, `gh release create`).
- Собрать exe и проверить на Windows: скачивание моделей, пути с кириллицей,
  архивы 7z и rar.
- Прогнать 2–3 реальных кейса до открытия в exocad.

### 0.2: надёжность на реальных кейсах
- 10–20 кейсов: сравнение с exoplan и с ручной посадкой, разбор неудач.
- Сегментация на видеокарте (ONNX Runtime DirectML), сейчас идёт на процессоре.
- Журнал ошибок в файл без имён пациентов, установщик.
- Сканы гипсовых моделей и второй режим прикуса в программе.

### 0.3: ориентиры и плоскости
- Цефалометрические точки на КТ: автоматически и с ручной правкой на срезах.
- Франкфурт, HIP, Кампер, окклюзионная плоскость.
- Экспорт в координатах артикуляторов exocad. Нужна проверка в самом exocad.

### 0.4: эстетика
- Загрузка фронтального фото, совмещение по зубам, эстетический горизонт и
  средняя линия.
- Экспорт в эстетической системе.

### 0.5: артикулятор и движения в программе
- Монтаж в свой виртуальный артикулятор, углы из КТ и сканов.
- Импорт записей движений, проверка по сканам, подбор настроек артикулятора.
- FGP и контакты по зубам с выгрузкой в STL.

### 0.6: связь с exocad
- Автозагрузка кейса: имена файлов, проект, матрицы.
- Кнопки в exocad на наши функции, генерация сот. Только официальными
  средствами.

### 1.0
- Дообучение моделей на накопленных поправках.
- Справка для пользователя, обновления программы.
