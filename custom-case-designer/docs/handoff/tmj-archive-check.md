# Проверка на архиве КТ: головки против ALI, скаты, ССП

Исполнитель: Claude · Ветка: — (проверка на ПК, вне репозитория) · Каркас в общей ветке: см. доску · Состояние: можно начинать

## Ведомому

Цель: подтвердить пороги новой автоматики мыщелков на всех КТ, что есть на ПК, до того как врач
увидит её в программе.

Сделать (кейсы — по номеру, без имён; вывод — через фильтр путей, отдельным процессом):
1. Для каждого кейса с сегментацией: `lmk.condylar_heads` (вырезка найдена / нет), расстояние ALI —
   верхушка головки по сторонам, решение `cond.prefer_head`.
2. ССП по скату (`gd.eminence_profile`) и по всему черепу (как до 13.10) при окклюзионной и
   франкфуртской плоскостях; сколько вне 5–75°.
3. На каждом кейсе, где ALI заменён или ССП неправдоподобен: сагиттальный срез через Co с точками
   (ALI, головка) и профилем — картинка вне репозитория; вывод — одной строкой, верна ли замена.
4. Таблица и выводы — в обратной передаче этого файла; предложения по порогам `ALI_HEAD_MAX_MM` (4 мм),
   `SAGITTAL_PLAUSIBLE_DEG` (5–75°), `HEAD_MIN_FACES`, `SLOPE_BAND_MM` — с числами.

Можно менять: только этот файл. Код ядра не менять — предложения ведущему.

Готово, когда: таблица по всем кейсам; по каждой замене — вердикт по срезу.

Меши не были приняты за сегментацию: по одним названиям файла нельзя доказать, что это сегменты
нижней челюсти/черепа именно из соответствующей КТ, а не сторонний экспорт или скан. Локальная
переменная `CCD_PRIVATE_CASES` не задана, поэтому проверить сохранённые кейсы KStom и повторить
цепочку ALI → головка → скат невозможно. Для кейсов 1–53: ALI—Co, результат `prefer_head`, углы
ССП и число сторон вне 5–75° — **не проверено: нет доступных подтверждённых данных сегментации и
ориентиров**. Срезы и изображения не создавались.

### Вывод

Численных оснований менять `ALI_HEAD_MAX_MM` (4 мм), `SAGITTAL_PLAUSIBLE_DEG` (5–75°),
`HEAD_MIN_FACES` (40) или `SLOPE_BAND_MM` (6 мм) эта инвентаризация не даёт; значения оставить
без изменений до проверки реальных сегментаций. Нужно предоставить доступ к каталогу обезличенных
кейсов через `CCD_PRIVATE_CASES` или подготовить подтверждённые наборы сегментации/ориентиров.

Карте: Б.3 — проверка архива не завершена; требуется доступ к локальным сохранённым кейсам с
сегментацией нижней челюсти, черепа и ALI.
