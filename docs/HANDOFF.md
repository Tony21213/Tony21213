## Задачи для локальной сессии (по порядку)

### L0. Подготовка (10 мин)

crownai работает **в своей рабочей папке** (git worktree), отдельно от папок
Case Designer: ветку в чужой папке не переключать.

```
cd <папка репозитория>
git fetch origin
git worktree add ..\crownai claude/dental-ai-0me2qf
cd ..\crownai
git pull
py -3.11 -m venv .venv
.venv\Scripts\activate
pip install -e ".[viz,ai,dev]"
pytest -q tests/test_mesh.py tests/test_posterior_model.py
```

### L1. Разметка зубов на сканах архива (полчаса)

10 сканов челюстей из разных кейсов, по возможности разных сканеров, обе челюсти:

```
crownai scan-teeth "<скан>.stl" --jaw lower --picture %TEMP%\scan_01.png
```

- По картинке проверить: правильные ли номера, не перепутаны ли стороны, не пропущены ли зубы.
- Картинки не пушить: это анатомия пациента.
- В «Обратную передачу» — таблица: № скана (1–10), сканер, челюсть, зубов на скане, найдено верно, ошибки (какие номера), время.

### L2. Этап 0 плана: замер на архиве (лучше на ночь)

```
crownai build-library Y:\CAD-Data_2025 --out lab_library
crownai tune-rules Y:\CAD-Data_2025 --out profiles\rules_profile.json
crownai benchmark Y:\CAD-Data_2025 --n 20 --variants rules,profile,library --library lab_library --rules-profile profiles\rules_profile.json --out benchmark_report
```

- **Время:**
  - `build-library` — быстро;
  - `tune-rules` — около 1,5 часов, продолжает с места;
  - `benchmark` — до 3 минут на коронку на каждый вариант.
- **Пушить:** `profiles\rules_profile.json` и `benchmark_report\` (только хэши и картинки коронок). Папку `lab_library` не пушить: она в `.gitignore`.
- **В «Обратную передачу»:** итоговые строки `benchmark` (успешность и причины отказов по каждому варианту, отклонение от техника).

### L3. Железо (5 мин)

Записать в «Обратную передачу»:
- видеокарту (модель, объём памяти);
- процессор и объём памяти;
- версию Windows и есть ли WSL2.

От этого зависит этап 4 плана (обучение нейросети).

### L4. Teeth3DS+ (когда будет время)

- Скачать с https://osf.io/xctdy в папку **вне репозитория** (например `D:\datasets\teeth3ds`).
- Прочитать условия лицензии.
- Записать:
  - условия лицензии;
  - устройство папок: имена файлов, формат меток и точек — 2–3 строки из каждого JSON, без данных.

По этому облачная сессия напишет импорт.

### L5. Библиотеки зубов exocad (если опись ещё не сделана в Case Designer)

- Сначала проверить, нет ли описи в Case Designer: `git show origin/claude/lucid-euler-8zyldi:custom-case-designer/docs/ideas.md` (только чтение).
- Если нет — описать устройство папок библиотек: форматы (`.off`, XML), по файлу на зуб или общий, что в XML.
- Сами файлы не пушить: лицензия exocad.

## Следующие задачи облачной сессии (параллельно)
