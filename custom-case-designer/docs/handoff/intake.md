# Входной контроль кейса: кнопка и отчёт для клиники

Исполнитель: Claude · Ветка: lead/reports · Каркас в общей ветке: dcbfd59 · Состояние: каркас готов

## Ведомому

Цель: при получении кейса врач нажимает «Входной контроль» — программа показывает, чего не хватает
(КТ, сканы, фото), и сохраняет отчёт со скриншотами, который можно сразу отправить клинике.

Сделать:
1. `Session.intake_report(out_dir=None)`: `intake.ct_findings(self.case.vol, landmarks)` —
   точки кейса после поиска ориентиров (если ALI-CBCT ещё не запускали — запустить или предупредить:
   без точек мыщелки, уши и глазницы «не найдены»); `intake.scan_findings({"upper"/"lower":
   (вершины, грани)}, has_bite)` — `has_bite`: есть скан прикуса или челюсти в прикусе
   (`in_occlusion`); `intake.photo_findings(...)` — пока `False, False` (фото — с «Эстетикой»);
   `reports.save(intake.report(findings, case_label), папка, "intake")`. Возвращает находки
   (уровень, раздел, что, текст) и имена файлов. Проверка: тест сессии на фантоме.
2. `POST /api/intake` — фоновая задача; ответ — находки и файлы; ошибки — 400.
3. Интерфейс: кнопка «Входной контроль» в шаге «КТ» (или «Сканы», когда КТ нет); список «Чего не
   хватает» с уровнями, «Открыть отчёт» и «Открыть папку». В инкогнито — без путей.
4. Тесты: HTTP «кейс → входной контроль → intake.pdf и .png»; кейс без КТ — только сканы и фото.

Можно менять: `app/steps/ct.py` (метод и `route`), `app/web/steps/ct.js` (кнопка и отчёт; без КТ — в
`app/web/steps/scans.js`), `app/web/app.js` (действия), `app/web/style.css`, новые тесты.
Не трогать: `intake.py`, `reports.py`.

Готово, когда: новые тесты проходят; полный набор проходит; `git diff --check` чисто; отчёт
открывается из интерфейса на фантоме.

## Контракт

Источник истины — docstring `casedesigner/intake.py`, `tests/test_intake.py`, генератор —
`casedesigner/reports.py` (`docs/handoff/archive/passport.md`).
Сверх кода:
- Пороги (воксель 0,3 / 0,4 мм, край поля 5 мм, дыра от 3 мм, обрывок до 200 граней) подобраны на
  синтетике: на фантоме сканов края зубов у десны считаются дырами — уточнить на реальных сканах
  (архив, вне репозитория), итог — в обратной передаче.
- Имён пациентов в отчёте нет: подпись кейса — номер или дата, сканы — по челюсти.
- Смазанность КТ от движения — позже (ядро ведущего).
