# new-project — расширения для exocad

Набор доработок, расширяющих функционал exocad DentalCAD под собственные задачи.

Обход лицензий и защиты в проект не входит. Всё строится поверх штатных
возможностей программы и её файлов.

## Подход

exocad — закрытая программа, поэтому новые функции добавляются снаружи:

- **Настройки и библиотеки** — правка конфигурационных XML, библиотек
  материалов, имплантов и шаблонов.
- **Файлы проектов** — чтение и генерация XML-файлов проекта и заказа
  (например, `*.constructionInfo`), чтобы автоматически создавать и
  анализировать кейсы.
- **Обработка сеток** — пред- и постобработка STL/PLY, которые exocad
  принимает и экспортирует: проверка, исправление, пакетные операции.
- **Автоматизация** — запуск exocad с нужными параметрами, слежение за
  папками экспорта, автоматизация рутинных действий в интерфейсе.
