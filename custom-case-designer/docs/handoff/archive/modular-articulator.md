## Ведомому

Цель: в шаге «Экспорт» видно, что ушло в проект exocad и что сделать в exocad один раз; без
артикулятора на каждый кейс.

Сделать:
1. Сводка выгрузки (`export_exocad_articulator` → `exocad_articulator_export.export`): показать
   `project_parameters` — ССП, Беннетт, боковой сдвиг справа/слева, резцовый столик («в проекте
   exocad»); `inserts` — подобранная вставка и её ССП по сторонам (или «стандартные»);
   `library_installed` против `library_version` — «общий артикулятор установлен» или «скопируйте один
   раз». Проверка: HTTP-тест — ключи сводки и тексты в ответе.
2. Текст карточки «Для exocad с артикулятором»: папка артикулятора — общая, ставится в
   `library\articulator` один раз (сейчас — «скопируйте папку» на каждый кейс). Проверка: тест текста
   в `app.js` (как в `tests/test_mount_planes.py`).
3. Браузер на фантоме: выгрузка, сводка, заметки; в инкогнито — без путей.

Можно менять: `app/web/steps/export.js`, `app/web/style.css` (шаг «Экспорт»), `app/steps/export.py` (только
прокидка сводки), новые тесты. Не трогать: `exocad_articulator_export.py`, `exocad_facebow.py`.

Готово, когда: `pytest tests/test_exocad_articulator_export.py -q` и новые тесты проходят; полный
набор проходит; `git diff --check` чисто; сводка видна в браузере на фантоме.

## Контракт

Источник истины — docstring `exocad_articulator_export` (раздел «Модульный артикулятор»),
`project_parameters`, `set_tooth_parameters`, `exocad_facebow.write_library_articulator`,
`fit_insert` и тесты `tests/test_exocad_articulator_export.py` (раздел «модульный артикулятор»),
`tests/test_exocad_facebow.py::test_insert_family_and_fit`, `::test_library_articulator`.
Сверх кода:
- exocad берёт углы из параметров зубов проекта при открытии (кейс 4, копия K4m, 13.10: ССП 44/37,7,
  Беннетт 17,5/16,7 вместо 24,9/9,5 библиотеки) — для любого выбранного артикулятора.
- Вставку по умолчанию exocad берёт первую в списке, а не `CurrentCondylarInsertColor` (опыт 12):
  первая — «Прямая», в проекте — ССП прямой вставки. Выбор вставки из файла движений
  (`articulator_settings` + `Assignments` в `articulatormappings.xml`) — опыт 13, копия K4k, не
  проверен.
- Межмыщелковое: в exocad владельца регулируется и выгружается значением в проекте (входящие 13.10);
  запись в проект — `ICD_IN_PROJECT`, по умолчанию выключено до проверки копии K4i (МШР 97,3).
- Плоскость гипсовки общего артикулятора — средняя (SAM 2P); высота резцовой точки — в сводке
  (`plane_height_mm`).
