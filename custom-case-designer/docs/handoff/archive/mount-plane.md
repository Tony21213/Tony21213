# Плоскость монтажа: выбор в «Гипсовке» и плоскость по умолчанию в настройках

Исполнитель: Claude · Ветка: lead/mount-plane · Каркас в общей ветке: 2ce1fca..cb27f94 · Состояние: принято (14.10.2026)

## Ведомому

Цель: врач выбирает, по какой плоскости ставить модели (окклюзионная, франкфуртская, оси-орбитальная,
Кемпера, HIP, эстетическая, эстетическая через мыщелки); ССП и Беннетт считаются от неё; плоскость по
умолчанию — в настройках.

Дополнение ведущего (13.10, ветка `lead/exocad-aesthetic-views`): седьмая плоскость
`aesthetic_hinge` — «Эстетическая через мыщелки (шарнир точно)»: требует костей лица и Co_R/Co_L,
при нехватке — по `FALLBACK` на эстетическую. Для exocad она лучшая: головки точно на мыщелках, кнопка
«Вид Smile Design» — точный эстетический вид спереди, стандартные виды — с остатком (кейс 3: 0,9°,
заметка монтажа). В интерфейсе — как остальные (`available` её уже возвращает), в настройках — седьмой
вариант; рекомендовать её как значение по умолчанию для выгрузки в exocad.

Сделать:
1. `Session.articulation_mount(method, plane=None)`: в `JawCase.mount` — `plane`, ориентиры
   `self.landmarks` (мм КТ), шарнир, кости лица `face_points` (череп + верхняя челюсть). `plane=None` —
   выбор кейса, у нового кейса — `mount_planes.resolve(settings["mount_plane"], …)` с заметкой.
2. `Session.articulation_planes()` → `{"planes", "current", "default", "tilt"}`
   (`mount_planes.available(..., face=...)`, `relative_angles` для доступных); `GET /api/articulation/planes`;
   `POST /api/articulation/mount` принимает `"plane"`; ошибки 400 с названиями недостающих точек.
3. Настройка: `settings["mount_plane"]` в `settings.json` (по умолчанию `occlusal`, неизвестное —
   `occlusal`), `set_default_mount_plane(key)` (неизвестная — `ValueError`), маршрут — как у
   `segment_parts`; в окне настроек — «Плоскость монтажа по умолчанию» (семь вариантов, пояснение
   цепочки замен).
4. «Гипсовка»: выбор плоскости; у недоступных — чего не хватает и «поставить точки в шаге КТ»; у
   доступных — наклон к окклюзионной; смена → «Перемонтировать» → движения заново; углы подписаны
   «от <плоскость>». Линию шарнира рисовать по `guides.hinge` (центры головок), маркеры — по Co.
5. Выбор кейса — в `.ccdcase`; нет точек для сохранённой — по `resolve`, с заметкой.
6. Тесты: HTTP «выбор → монтаж → состояние»; нет точек → 400; настройка сохраняется между запусками;
   старый кейс без выбора. Реальный кейс по номеру: ССП и наклоны для доступных плоскостей.

Можно менять: `app/session.py`, `app/server.py`, `app/web/app.js`, `app/web/style.css` (шаг «Артикулятор»,
настройки), новые тесты. Не трогать: `mount_planes.py`, `jawcase.py`, `exocad_webview.py`, `aesthetic.py`.

Готово, когда: `pytest tests/test_mount_planes.py -q` — без xfail; полный набор проходит;
`git diff --check` чисто; выбор и настройка работают в браузере на фантоме.

## Контракт

Источник истины — `mount_planes` (`PLANES`, `FALLBACK`, `available`, `resolve`, `rotation`,
`relative_angles`, `base_for_aesthetic`), `JawCase.mount(plane=…, landmarks=…, face_points=…)`,
`exocad_webview.mount` (docstring) и `tests/test_mount_planes.py`. Сверх кода:
- Точки черепа — мм КТ (неподвижны с верхней челюстью), мыщелки — в прикусе монтажа.
- Шарнир — центры головок: 4 мм (`guidance.CONDYLE_RADIUS_MM`) ниже Co по «вверх» монтажа; точки
  врача, проверки, маркеры — Co. Профиль бугорка — от Co, ССП от этого не меняется.
- Эстетическая: крен, разворот, средняя линия — по симметрии лицевого скелета на КТ (позже — по фото),
  наклон — от франкфуртской, если есть Po и Or, иначе от окклюзионной; углы суставов — от базовой
  горизонтали (`Settings.frame`), в артикулятор exocad — с пересчётом.
- Po, Or, Co находит ALI-CBCT; Tr, Al, HN — только врач (Кемпер, HIP).
- Кейс 3 (12.10): ССП П/Л — окклюзионная 9,5/24,9, франкфуртская 30,8/36,0, оси-орбитальная 40,0/42,7;
  головки от мыщелков — 3,2 / 1,8 / 0,0 мм, эстетическая — 0,7 мм; окклюзионная скошена к лицу на 3°.
  Эстетическая через мыщелки (13.10): ССП 30,5/36,1, головки 0,0 мм, остаток к эстетике 0,9°.
- Эстетическая через мыщелки: ось «вправо» — линия мыщелков, «вверх» — эстетическое поперёк неё
  (`mount_planes.rotation(..., face_up=…)`); эстетическая система кейса — `JawCase.aesthetic_axes`
  (есть у обеих эстетических), по ней выгрузка пишет `.treatmentImages` (`exocad_views`).
