# crownai — правила работы

crownai — некоммерческий аналог exocad AI Design: предложение коронки по
сканам и `.constructionInfo`, обучение на готовых коронках лаборатории.

- **План:** `docs/ROADMAP.md`.
- **Передача и текущие задачи:** `docs/HANDOFF.md`. Её при запуске читать первой.

## Общение

- С владельцем — по-русски, просто и без жаргона: он зубной техник, а не программист.

## Ветка и соседний проект

- Работа идёт в ветке `claude/dental-ai-0me2qf`, push: `git push -u origin claude/dental-ai-0me2qf`.
- На ПК crownai живёт в **своей рабочей папке** (`git worktree add ..\crownai claude/dental-ai-0me2qf`).
  В папках Case Designer ветку не переключать: там работают его сессии.
- В этом же репозитории живёт отдельный проект **KStom Case Designer**: папка
  `custom-case-designer/`, ветки `claude/lucid-euler-8zyldi`, `lead/*`,
  `follower/*`. **В нём ничего не менять:** ни файлов, ни веток, ни его доски.
  Брать оттуда полезное можно только копированием в `crownai/`, с пометкой
  об источнике (так взят `crownai/scan_seg.py`). Границы проектов —
  `docs/ROADMAP.md`, раздел 1а.

## Данные пациентов

- **В git — никогда:**
  - сканы (STL, PLY, OBJ);
  - HTML-выгрузки;
  - папки кейсов, `.constructionInfo`;
  - имена пациентов;
  - пути к папкам архива (в именах папок — фамилии);
  - библиотека коронок `lab_library/`;
  - файлы `*.fits.jsonl`;
  - картинки сканов челюстей.
- **Можно пушить:**
  - код и тесты;
  - `profiles/*.json`;
  - отчёт `benchmark_report/` (`summary.json`, `results.jsonl`, картинки коронок);
  - документы.
- **Ошибки и отчёты:** id кейсов только хэшами, пути вырезаются (`rules_tuning._safe_error`).
- **Перед каждым коммитом:** проверить `git diff --cached --stat`, найти в изменениях `Y:`, `\\` и фамилии.
- **Архив** (`Y:\CAD-Data_2025`) — только чтение. В папки кейсов ничего не писать: у `construction-case` всегда указывать `--out-dir` вне архива.

## Установка и запуск (Windows)

```
py -3.11 -m venv .venv
.venv\Scripts\activate
pip install -e ".[viz,ai,dev]"
```

- Нейросеть разметки зубов (`crownai scan-teeth`) при первом запуске скачивается сама в `%USERPROFILE%\.crownai\models` (или в папку из `CROWNAI_MODELS`), с проверкой SHA-256.
- Тесты: `pytest -q`, около 7 минут. В ответ владельцу — только итоговая строка.
- Долгие прогоны (`build-library`, `tune-rules`, `benchmark`) можно прерывать: `build-library` и `tune-rules` продолжают с места.

## Коммиты

- Понятное сообщение на английском, что и зачем.
- Идентификаторов моделей в коде и сообщениях нет.
- Прежде чем закончить: коммит, push и обновлённый `docs/HANDOFF.md` (раздел «Обратная передача»), чтобы следующая сессия, облачная или локальная, продолжила без пересказа владельца.
