# Порог предупреждения о перекосе дуги

## Обратная передача
Исполнитель: Codex · Ветка: follower/pc-checks · Коммит: этот коммит (история файла).
Сделано: б) `quality.py`: SHIFT_WARN_MM 0,1 → 0,3 мм; P90_WARN_MM 0,25 → 0,4 мм.
Изменены также `tests/test_quality.py` и этот файл; алгоритм подгонки и интерфейс не менялись.
Обоснование P90: в кейсе №2 после уточнения 0,3293/0,3327 мм (НЧ/ВЧ),
при сохранённых положениях 0,3366/0,3355 мм; 0,4 мм снимает постоянное общее предупреждение.
Это рабочий порог по двум КЛКТ, не клиническая валидация и не критерий точности ≤0,4 мм.
Отклонения от цели: «предупреждать только при настоящем перекосе» пока не подтверждено.
Метод: сохранённые матрицы → CaseCT.evaluate; затем register(start=матрица);
опора — сохранённая сегментация зубов; дополнительно поворот боковой части дуги на 2° и 5°.
Реальный кейс №1: после уточнения P90 ВЧ/НЧ 0,4047/0,3568 мм,
максимальный локальный сдвиг 0,648/92,853 мм; совпало лишь 5,4/13,8% всех вершин.
Для калибровки нормы исключён: плохое совмещение и неустойчивая локальная подгонка.
Реальный кейс №2: после уточнения локальный максимум ВЧ/НЧ 0,482/0,618 мм;
локальных предупреждений становится 2/3 вместо 6/6, общий P90 больше не предупреждает.
Кейс №2 с искусственным перекосом 2°: максимум ВЧ/НЧ 0,419/0,691 мм;
5°: 0,494/0,586 мм; порог 0,3 мм сохраняет предупреждения, но исходный кейс тоже их имеет.
Ограничение: нет независимой разметки истинного перекоса; различить склейку, сегментацию
и расхождение с КТ только изменением двух порогов нельзя. MATCH_WARN_RATIO не менялся.
Проверки до правки: test_quality — 3 passed; после: test_quality + test_registration —
20 passed, 82 warnings (устаревающий API scikit-image), 208,25 с; git diff --check — чисто.
