# Соты в модели

Делает модель полой, а полость разбивает на шестигранные ячейки, открытые со
стороны основания. Модель становится легче и тратит меньше материала при
печати, наружная поверхность остаётся без изменений.

![Пример](preview.png)

## Установка

Нужен Python 3.10 или новее.

```
pip install -r requirements.txt
```

## Использование

1. Экспортируйте модель из exocad в STL (например, результат Model Creator).
   Модель должна быть замкнутой, а основание — плоским и лежать внизу по оси Z.
2. Запустите:

   ```
   python honeycomb.py model.stl model_honeycomb.stl
   ```

3. Откройте `model_honeycomb.stl` в exocad или в программе для печати.

## Параметры

| Параметр | По умолчанию | Описание |
|---|---|---|
| `--wall` | 1.2 | Толщина наружной стенки, мм |
| `--cell` | 5 | Размер ячейки между параллельными гранями, мм |
| `--inner-wall` | 1.2 | Толщина стенок между ячейками, мм |
| `--max-height` | вся модель | Высота сот над основанием, мм |
| `--perf-diameter` | 0 | Диаметр перфорации внутренних стенок, мм (0 — без неё) |
| `--perf-height` | у основания | Высота центра перфорации над основанием, мм |
| `--open-side` | bottom | С какой стороны по оси Z открыты соты: `bottom` или `top` |
| `--layer` | 0.2 | Шаг построения, мм. Меньше — точнее внутренние своды, но дольше |

Пример с ограничением высоты и перфорацией:

```
python honeycomb.py model.stl out.stl --wall 1.5 --cell 4 --max-height 10 --perf-diameter 1
```
